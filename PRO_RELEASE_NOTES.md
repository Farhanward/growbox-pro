# GrowBox Pro Release Notes

## What This Build Contains

- `GrowBox Pro` is a separate copy from the original `C:\Projects\reach-optimizer`.
- Paid feature gate with offline Ed25519 license codes.
- 30-day subscription codes generated by `GrowBox License Manager`.
- Renewal warning during the final 4 days with the company phone: `+966504211844`.

## Required Seller Configuration

Before commercial distribution, replace the development signing keypair:

- Client public key: `src-tauri/src/license.rs`, `PUBLIC_KEY_HEX`.
- Manager private seed: `C:\Projects\reach-optimizer-license-manager\src-tauri\src\lib.rs`, `SIGNING_SEED_HEX`.

The current key is a public RFC 8032 test vector so the local prototype works end to end. Do not sell builds using that key.

OAuth requires developer credentials at runtime/build environment:

- `GROWBOX_TIKTOK_CLIENT_KEY`
- `GROWBOX_TIKTOK_CLIENT_SECRET`
- `GROWBOX_TIKTOK_REDIRECT_URI`
- `GROWBOX_INSTAGRAM_CLIENT_ID`
- `GROWBOX_INSTAGRAM_CLIENT_SECRET`
- `GROWBOX_INSTAGRAM_REDIRECT_URI`
